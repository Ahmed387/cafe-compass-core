# الهالك مش بيدخل في تكلفة المشروب

قرار صاحب الكافيه (2026-10-16): الهالك المتوقع صفة لكل خامة في المخزن الكبير (نسبة أو كمية ثابتة لكل وحدة شراء)، وبيتعرض لوحده كقيمة متوقعة، ومش بيتضاف على تكلفة المشروب وقت البيع. الخسارة الحقيقية بتدخل الأرباح مرة واحدة بس، لما الجرد يكشفها.

## Considered Options

- إضافة الهالك على تكلفة كل مشروب وقت البيع: اترفضت لأن نقص الجرد بعد كده كان هيتخصم تاني (مرتين)، ولأن الصنف اللي هالكه محصلش كان هيتحمّل تكلفة وهمية.
