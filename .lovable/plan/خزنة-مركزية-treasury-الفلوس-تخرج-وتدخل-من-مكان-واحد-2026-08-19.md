# خزنة مركزية (Treasury) — الفلوس تخرج وتدخل من مكان واحد

## الوضع الحالي

مفيش خزنة مجمعة. كل حركة فلوس متسجلة في جدولها لوحدها:

- مبيعات: مدفوعات الأوردرات + المرتجعات
- ورديات: كاش افتتاحي/متوقع/فعلي + الفرق
- مشتريات: دفعات الموردين
- مصاريف تشغيل + رواتب وسلف
- شركاء: رأس مال + سحب + توزيع أرباح

يعني الأرقام كلها موجودة، بس مفيش **رصيد واحد** يقولك "الخزنة فيها كام دلوقتي" ولا شاشة تصرف منها.

## اللي هيتم بناؤه

### 1. حسابات نقدية (Cash Accounts)

جدول حسابات: خزنة الكاشير (درج)، الخزنة الرئيسية (كاش)، حساب بنكي/فيزا، محفظة إلكترونية.
كل حساب له: الاسم، النوع، الرصيد الافتتاحي، هل نشط.

### 2. حركة الخزنة (Cash Transactions)

جدول واحد لكل حركة داخلة/خارجة، بيربط الحركة بمصدرها:

- **داخل**: تحصيل مبيعات وردية، رأس مال شريك، تحصيل مرتجع مورد
- **خارج**: دفع مورد، مصروف تشغيل، راتب/سلفة، سحب شريك، قسيمة عميل كاش
- **تحويل**: من درج الكاشير للخزنة الرئيسية، أو من الخزنة للبنك

الرصيد بيتحسب من الحركات (مش رقم محفوظ) فمفيش فرصة لتضارب.

### 3. الربط الأوتوماتيك

- تقفيل وردية → توريد الكاش الفعلي للخزنة الرئيسية أوتوماتيك (والفرق يتسجل كعجز/زيادة)
- دفع مورد / اعتماد مصروف / صرف راتب أو سلفة / سحب شريك → حركة خروج أوتوماتيك من الحساب المختار
- كل حركة خروج **لازم تحدد الحساب وطريقة الدفع** (كاش / فيزا / تحويل / محفظة) + مرجع اختياري
- منع الصرف لو الرصيد مش كافي (اختياري: تحذير بدل منع، هتقرر)

### 4. شاشة "الخزنة" جديدة في السايد بار

- كروت أرصدة: الخزنة الرئيسية، البنك/فيزا، درج الورديات المفتوحة، الإجمالي
- جدول الحركات بفلترة (تاريخ / نوع / حساب / مين عملها)
- أزرار: إيداع، صرف، تحويل بين الحسابات
- صلاحيات جديدة: `treasury.view` / `treasury.manage` (سوبر أدمن + محاسب فقط)

### 5. لوحة التكاليف التشغيلية الشهرية

شاشة بتقولك بالضبط فلوس التشغيل رايحة فين كل شهر:

- **استهلاك البضاعة**: كمية وتكلفة كل صنف اتصرف فعلياً خلال الشهر (من حركات المخزون: بيع + هالك + تسويات) — يعني "استهلكنا 120 كيلو لبن بتكلفة كذا"
- **مشتريات الشهر**: المدفوع فعلاً للموردين + المتبقي دين
- **رواتب وسلف**: إجمالي المصروف على العمال
- **مصاريف ثابتة/متغيرة**: إيجار، كهربا، صيانة... مقسّمة بالبند
- **إجمالي التكلفة التشغيلية** + نسبة كل بند من المبيعات (نسبة تكلفة البضاعة، نسبة الرواتب...) لمقارنة شهر بشهر

### 6. حساب صافي الربح والتوزيع الأوتوماتيك

```
مبيعات الشهر (بدون ضريبة)
- تكلفة البضاعة المستهلكة (COGS)
- الهالك
- المرتجعات
= الربح الإجمالي
- مصاريف تشغيل + إيجار
- رواتب وسلف
= صافي الربح
- الاحتياطي التشغيلي (نسبة أو مبلغ ثابت يحدده السوبر أدمن في الإعدادات)
= المتاح للتوزيع  →  يتوزع تلقائي على الشركاء بنسبة حصة كل واحد
```

بمجرد تقفيل الفترة المحاسبية، نصيب كل شريك يتقيّد أوتوماتيك في **رصيده**.

### 7. رصيد الشريك + طلبات السحب بموافقة السوبر أدمن

- كل شريك له صفحة برصيده الحالي = رأس المال + الأرباح الموزعة − السحوبات
- الشريك يقدر يفتح **طلب سحب** (مبلغ + طريقة الاستلام + ملاحظة)
- الطلب يوصل السوبر أدمن كإشعار: **موافقة / رفض** (مع سبب الرفض)
- الموافقة بتعمل حركة خروج فعلية من الخزنة + قيد سحب في دفتر الشريك
- منع الطلب لو أكبر من الرصيد المتاح أو من رصيد الخزنة
- الشريك يشوف حالة طلباته (قيد المراجعة / مقبول / مرفوض) وسجل سحوباته

## تفاصيل تقنية

- جداول جديدة: `cash_accounts`, `cash_transactions` (+ GRANT و RLS مربوطة بالشركة والصلاحيات، append-only مع عكس بحركة مضادة بدل الحذف)
- دوال: `cash_balance(account)`, `post_cash_txn(...)`, `deposit_shift_cash(shift)`, `transfer_cash(from,to,amount)`
- تعديل الدوال الحالية: `close_shift`, `record_purchase_payment`, `approve_expense`, `salary_payments`, `distribute_period_profit` تسجّل حركة خزنة
- جدول `partner_withdrawal_requests` (مبلغ، طريقة الدفع، الحالة، مين وافق/رفض والسبب) + دالة `request_withdrawal` و `review_withdrawal`
- دالة `monthly_operating_costs(from,to)` بتجمع استهلاك المخزون بالتكلفة + المشتريات + الرواتب + المصاريف بالبند
- توسيع `period_pnl` بالاحتياطي التشغيلي والمتاح للتوزيع
- إعداد جديد في الإعدادات: نسبة/مبلغ الاحتياطي التشغيلي
- شاشة جديدة `src/routes/_authenticated/treasury.tsx` + بند في السايد بار + ترجمة عربي/إنجليزي
- حماية الفترات المحاسبية المقفولة بتنطبق على حركات الخزنة كمان
